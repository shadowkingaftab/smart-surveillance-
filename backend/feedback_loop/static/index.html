  1. Run the API on this laptop and open this page at http://127.0.0.1:8000.
  2. Click Start camera and allow camera access.
  3. For AI, install requirements, add model files, and set the API token before starting the API.

The browser camera is available on localhost (or HTTPS). Opening this page from another device by LAN IP requires HTTPS.
